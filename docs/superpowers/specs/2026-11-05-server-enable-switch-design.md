# 服务器启用/禁用开关 — 设计

日期：2026-11-05
状态：待批准
相关：`docs/design.md` §3.1、§4.2、§5、§8

---

## 意图

一台配置好的服务器有时需要**暂时退出使用**：维护窗口、临时停用、等排障结束。
现在只有两个选择——留着（agent 仍可能去用）或者删掉（配置连同密码一起丢失）。
启用/禁用开关补上中间这一档：**保留配置，但让 agent 看不到、用不了**。

## 目标

- 新增服务器默认启用；启用状态可一键切换，**不走待确认区**。
- 禁用后：`srv_list` 不返回它，系统提示不列它，任何 `srv_*` 调用被拒绝。
- 已建立连接的服务器**不允许禁用**。

## 非目标

- 不做「定时禁用」「按会话禁用」「只读模式」。
- 不因为禁用而断开连接池里的连接——前置条件已经保证禁用时没有活连接。
- 不在 `servers.json` 之外另建状态文件。

## 反目标（这样算失败）

- 禁用后模型仍能从系统提示或 `srv_list` 看到这台机器，从而反复尝试、反复被拒。
- 禁用后配置丢失，或者需要重新填密码才能恢复。
- 禁用变成了「删除」的别名，导致用户不敢用。

## 方案

选定的做法：**记录上新增 `enabled` 布尔字段，在三个出口同时生效**。

否决的替代方案：

1. **只在 `#resolveServer` 拦截**（不做列表过滤）。实现最省，但系统提示和 `srv_list`
   仍会列出被禁用的机器，模型会持续尝试并拿到 `SERVER_DISABLED`，这正是反目标。
2. **复用 `disabledRules` 语义**（把整台机器的所有规则停用）。语义错位：规则停用
   是「放宽限制」，禁用服务器是「这台机器不可用」，且前者仍允许执行命令。

## 实现要点

### 数据（§3.1）

`servers.json` 每条记录新增：

```jsonc
"enabled": true
```

缺省视为 `true`（向后兼容：旧文件没有这个字段，加载时补上）。校验只接受布尔值。

### 判定（§5）

三个出口必须一致，缺一个就破坏反目标：

| 出口 | 行为 |
|---|---|
| `#resolveServer` | 解析到的记录 `enabled === false` → 抛 `SERVER_DISABLED` |
| `srv_list` | 过滤掉 `enabled === false` 的记录 |
| 系统提示 `renderServerSection` | 同样过滤 |

`#resolveServer` 覆盖 `srv_exec`、`srv_connect`、`srv_policy_check`（以及经它解析的
job 工具），所以「三个工具都拒绝」不需要各写一遍。

**前缀歧义的处理**：解析先按 id/name/前缀找候选。若命中的候选里只有已禁用项，
报 `SERVER_DISABLED`；若既有启用项又有禁用项，按既有规则报 `AMBIGUOUS_SERVER`
（不因禁用而改变歧义语义，避免同一个前缀的解析结果随开关状态漂移）。

`SERVER_DISABLED` 的下一步提示固定为：在面板的「服务器」页启用后再试。

### 开关接口（§8.5）

复用既有的更新路由，`PUT /server-connector/servers/:id` 接受 `enabled` 字段：

- `enabled: false` 且 `pool.isConnected(id)` 为真 → **409 `SERVER_CONNECTED`**，
  提示先断开。这是用户明确要求的前置条件。
- 切换**不进入待确认区**：禁用是收紧限制（让机器不可用），比删除更安全；
  启用则恢复既有配置，二者都不放宽任何规则。
- 每次切换写一条审计事件：`server-disabled` / `server-enabled`。

### UI（§8.2）

列表行右侧加一个 switch，与「测试 / 编辑」同区。已连接时 switch 置灰并给 tooltip
（`先断开再禁用`）。禁用的行整体降低对比度，并在行内显示「已禁用」标签，
保证**禁用后仍在 UI 可见**——这是与 `srv_list` 有意不同的处理：模型不该看见，
用户必须看得见，否则没有入口把它恢复。

## 风险

| 风险 | 缓解 |
|---|---|
| 用户以为禁用等于删除 | 禁用行保留在 UI，标注「已禁用」，随时可开 |
| 系统提示被禁用项挤占名额 | 过滤在前，`maxListedServers` 截断在后 |
| 忘记断开就禁用 | 409 明确拒绝，不静默断开用户的长连接 |

## 验收

- 默认新建为启用；旧 `servers.json` 无该字段时加载为启用。
- 禁用后 `srv_list` 返回的空列表（单机场景）与系统提示为空。
- `srv_exec` / `srv_connect` / `srv_policy_check` 对已禁用服务器均抛 `SERVER_DISABLED`。
- 已连接时禁用返回 409，断开后可禁用。
- 切换写审计，且不产生待确认记录。
